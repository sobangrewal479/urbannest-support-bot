# UrbanNest Website AI Support Bot + Lead Capture

## Project Overview

UrbanNest Website AI Support Bot + Lead Capture is a portfolio Django project built for a mock furniture business based in Chicago, USA.

The project includes a customer-facing AI-style support bot that answers common furniture questions and helps capture quote requests from interested website visitors.

This is a portfolio/MVP version. In a real client project, the lead view would normally be upgraded into a secure owner dashboard/admin portal with login protection.

## Purpose

The purpose of this project is to help a furniture business:

- Answer repeated customer questions
- Provide basic product and pricing guidance
- Detect quote/contact intent
- Capture customer lead details
- Save leads for the business owner to review

## Main Features

- Customer-facing chatbot page
- Rule-based AI-style bot responses
- FAQ and product/service answering
- Furniture category guidance
- Starting price guidance in USD
- Quote/contact intent response
- Lead capture form
- Lead validation
- Lead storage in database
- Owner lead list page
- Safe fallback for outside-scope questions
